# E0.1 Monorepo, tooling, CI/CD, docker compose

## Goal
A reproducible workspace where every later package and app gets lint, typecheck, tests and CI for free, and the dev servers start with one command.

## Read first (only these)
- docs/01-architecture.md: repo layout, environments, Definition of Done (section 12)
- docs/13-devops-and-runbooks.md: environments, env vars, CI/CD
- docs/14-conventions.md: TypeScript, lint and git rules (lines 1-10, 54)

## Scope
- [x] git repo, pnpm workspace, Turborepo, EditorConfig, Prettier, strict `tsconfig.base.json`
- [x] `pnpm verify` quiet gate runner (`scripts/verify.mjs`) including the theme contrast check
- [x] `packages/config`: shared ESLint flat config (typescript-eslint strict type-checked, import order, unicorn subset) with custom rules `dairy/no-hardcoded-colors`, `no-hardcoded-text`, `no-physical-css`, `no-direct-fetch`, all unit-tested; proven on a deliberately bad file
- [x] `packages/config` tsconfig presets (node, react-lib, next, expo)
- [x] husky + lint-staged pre-commit; commitlint (Conventional Commits) on commit-msg, proven to reject a bad message

## Notes / decisions made while working
- See ADR-019 (docs/15): RustFS for local S3, TypeScript pin, denied install scripts, DB roles.
- `lint`, `typecheck` and `test` only cover packages that define those scripts (today: `@dairy/config`). Each new package must define them.
- `verify:full` has no extra gates yet; integration/RLS, build and e2e are added as they exist.
- Prettier ignores `docs/`, `CLAUDE.md`, `README.md`, `Mockups/` and skills so prose and tables are not reflowed.
